# Project Gallery of Vanilla JS

A collection of small games and tools built with plain HTML, CSS, and JavaScript. No frameworks, no build step.

## Games

1. [Snake & Ladder](./snake-ladder/) — Classic board race for 2–3 players with a 3D dice
2. [Tic-Tac-Toe](./tic-tac-toe/) — Classic two-player X and O duel
3. [Connect Four](./connect-four/) — Drop discs and line up four in a row
4. [Memory Game](./memory-game/) — Flip the cards and match every pair
5. [Racing Car](https://codingdestro.github.io/racingcar/) — A retro-style racing game (External)

## Tools

6. [Calculator](./calculator/) — Clean calculator UI for quick math
7. [Calendar](./calendar/) — Monthly calendar with year navigation
8. [Clock](./clock/) — Analog wall clock with live sweeping hands
9. [Password Generator](./password-gen/) — Generate strong random passwords in one click
10. [EMI Calculator](./emi-calculator/) — Work out monthly loan payments
11. [Age Calculator](./age-calc/) — Exact age from a birthdate, down to the day
12. [Habit Tracker](./habit-tracker/) — Track daily habits with streaks, heatmap & calendar

## UI

13. [Animated Card](./animated_card/) — A CSS-powered animated card design study
